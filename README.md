## 📂 Proyectos Incluidos

### 1. [Optimización de Portafolios y Machine Learning (PROYECTO FINAL.ipynb)]
Desarrollo integral de un marco cuantitativo para gestión de activos, análisis de riesgo y predicción bursátil.

* **Análisis de Riesgo y Rendimiento**: Rendimientos logarítmicos, matriz de correlación, asimetría, curtosis, VaR y CVaR.
* **Optimización de Portafolios**: Maximización del Ratio de Sharpe y frontera eficiente mediante optimización convexa (`cvxpy`).
* **Econometría y Volatilidad**: Modelación de series temporales mediante GARCH (`arch`).
* **Machine Learning No Supervisado**: Reducción de dimensionalidad con PCA y clustering de activos (K-Means, DBSCAN, Jerárquico).
* **Simulación Estocástica**: Proyección de trayectorias con Simulación Monte Carlo.
* **Modelos Predictivos**: Regresores SVR y Random Forest evaluados mediante error cuadrático medio (MSE).
