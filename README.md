## 📂 Proyectos Incluidos

### 1. [Optimización de Portafolios y Machine Learning (Analisis de Inversiones con Python.ipynb)]
Desarrollo integral de un marco cuantitativo para gestión de activos, análisis de riesgo y predicción bursátil.

* **Análisis de Riesgo y Rendimiento**: Rendimientos logarítmicos, matriz de correlación, asimetría, curtosis, VaR y CVaR.
* **Optimización de Portafolios**: Maximización del Ratio de Sharpe y frontera eficiente mediante optimización convexa (`cvxpy`).
* **Econometría y Volatilidad**: Modelación de series temporales mediante GARCH (`arch`).
* **Machine Learning No Supervisado**: Reducción de dimensionalidad con PCA y clustering de activos (K-Means, DBSCAN, Jerárquico).
* **Simulación Estocástica**: Proyección de trayectorias con Simulación Monte Carlo.
* **Modelos Predictivos**: Regresores SVR y Random Forest evaluados mediante error cuadrático medio (MSE).

### 2.📊 Executive Overview & Business Intelligence

Este dashboard fue diseñado bajo un enfoque integral de Business Intelligence para optimizar la toma de decisiones mediante el análisis transversal del rendimiento comercial. El proyecto se apoya en un modelo de datos estructurado en Power BI —con relaciones de cardinalidad optimizadas y filtrado cruzado eficiente— que consolida métricas clave como ingresos brutos, neto y rentabilidad ponderada. Esta arquitectura permite evaluar el desempeño a través de diferentes dimensiones del negocio, tales como ubicación geográfica, categorías de producto y tendencias temporales.
